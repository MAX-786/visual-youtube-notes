Note generation: what happens when the model gets it wrong

The note model is asked for one JSON object. Constrained decoding guarantees the shape is right, but nothing more — not the word limits, not how many key points, not whether the diagram is a real tree, and above all not whether the quotes it cites were ever actually said. This demo asks: when the model gets one of those wrong, can we fix it ourselves, or do we have to pay to ask again? Everything below runs against a real transcript of a real 18-minute video.
